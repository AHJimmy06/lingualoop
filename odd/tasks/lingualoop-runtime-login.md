## Constraints and verification priority
Use `localhost:5000` API and `localhost:5001` web; no public domain. Reuse **only** NousAI's Google client ID/secret, never its JWT key, DB, tokens, data or entire `.env`. The LinguaLoop signing key and Google env file live outside the repository, mode 0600. Leave NousAI, the private LinguaLoop PostgreSQL volume, existing `.gitignore` and unrelated untracked files untouched. No push, PR, publication or retirement of old modules without user approval. TDD disabled by prior user choice; RDD switch off. Keep each substantial task a local feature-branch work-unit commit with focused checks and honest runtime evidence. The user explicitly prefers observable browser behavior over increasing an offline test count: prioritize a clickable vertical slice and tests only where they protect concrete risks. A Google 302 or passing suite does not prove live login.
